# Personal Portfolio Website - Madhav Pratap Singh

A clean, minimal, responsive personal portfolio website created using only semantic **HTML5**, modern **CSS3**, and **Vanilla JavaScript**. Built with a modern design system free of gradients, glassmorphism, or flashy animations.

---

## 🌟 Features

- **Minimal & Modern Aesthetic**: Clean layout featuring curated color tokens (`#F8F9FA` background, `#111827` primary text, `#2563EB` accent, `#E5E7EB` borders, `#FFFFFF` cards).
- **Responsive Layout**: Designed mobile-first using CSS Flexbox, CSS Grid, and media queries for seamless display across Desktop, Tablet, and Mobile devices.
- **7 Core Sections**:
  1. **Header & Navigation**: Fixed header with brand title, active section highlighting, and mobile hamburger drawer.
  2. **Hero Section**: Headline, subtitle, brief intro, and call-to-action buttons ("Hire Me" and "View Projects").
  3. **About Me**: Cards detailing introduction, education, career goal, and interests with a toggleable "More About Me" section.
  4. **Skills**: Modular cards highlighting core web development tools (HTML, CSS, JavaScript, Git, GitHub).
  5. **Projects**: Showcase of 3 key full-featured projects complete with SVG layout preview, descriptions, tech tags, GitHub links, and Live Demo buttons.
  6. **Contact**: Interactive contact form with real-time field validation, along with direct email, LinkedIn, and GitHub links.
  7. **Footer**: Clean copyright footer statement.
- **Interactive JavaScript Features**:
  - Alert modal triggered by the "Hire Me" button.
  - Smooth accordion toggle for "Show More About Me" / "Show Less About Me".
  - Real-time client-side contact form validation (Email format check, empty field check, error/success messages).
  - Smooth scrolling navigation and dynamic section highlight.
  - Scroll-to-top floating button that appears on page scroll.

---

## 🛠️ Built With

- **HTML5**: Semantic markup (`<header>`, `<nav>`, `<main>`, `<section>`, `<article>`, `<form>`, `<footer>`) for SEO and accessibility.
- **CSS3**: CSS Custom Properties (Variables), Flexbox, CSS Grid, custom SVGs, and responsive media queries.
- **Vanilla JavaScript (ES6+)**: DOM manipulation, event listeners, form validation, and scroll observers.
- **Typography**: [Inter Font](https://fonts.google.com/specimen/Inter) from Google Fonts.

## 🚀 Getting Started

### 1. View Locally in Browser
You don't need any build tools or dependencies! Simply clone or download the repository and open `index.html` directly in any web browser:

```bash
# Clone the repository
git clone https://github.com/madhav-pratap-singh/portfolio.git

# Navigate to project directory
cd portfolio

# Open in browser (macOS)
open index.html

# Open in browser (Windows)
start index.html
```

Or using standard Python local server:
```bash
python3 -m http.server 8000
# Then visit http://localhost:8000 in your browser
```

---

## 🌐 Deployment to GitHub Pages

1. Push this repository to GitHub.
2. In your GitHub repository, go to **Settings** > **Pages**.
3. Under **Build and deployment**, select **Deploy from a branch**.
4. Choose **main** (or **master**) branch and `/ (root)` folder.
5. Click **Save**. Your portfolio will be live in a few moments at `https://<your-username>.github.io/<repo-name>/`.
